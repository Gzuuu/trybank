# 🏦 Trybank  

## 📋 Descrição Breve  
O **Trybank** é uma aplicação de controle de contas bancárias, permitindo realizar operações básicas como checar saldo, depositar, sacar, transferir dinheiro, cadastrar novas contas, e realizar login/logout no sistema. Desenvolvido durante o aprendizado de C# básico, este projeto foi fundamental para aprender algoritmos e funcionalidades essenciais em um ambiente de console.  

## 🛠️ Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash  
   git clone https://github.com/Gzuuu/trybank.git  
   ```  
2. Entre na pasta do projeto:  
   ```bash  
   cd trybank/src  
   ```  
3. Instale as dependências:  
   ```bash  
   dotnet restore  
   ```  

## 💻 Tecnologias Utilizadas  
- **📝 Linguagem**: C#  
- **⚙️ Framework**: .NET  

## ⚙️ Funcionalidades  
- 💳 **Checar saldo** de contas.  
- 💵 **Depositar, sacar e transferir dinheiro** entre contas.  
- 📝 **Cadastrar novas contas** no sistema.  
- 🔐 Realizar **login e logout**.  

## 🌟 Principais Aprendizados  
- 🛠️ Construção de algoritmos em **C#**.  
- 🚨 Lançamento de **exceções controladas**.  
- 📚 Manipulação de **arrays e variáveis** em C#.  
- 🖥️ Desenvolvimento de **aplicações em console** utilizando .NET.
